# Visual evidence: provenance and preparation

[Project overview](../../README.md) · [Resumen](../../README.es.md)

These files were supplied by the project owner as evidence of the three-person team's academic prototype. Captions describe what is visible and should be read with the contribution table in the main README. Photographing, storing or publishing a team assembly does not attribute every component to one contributor.

The supplied photographs contain no EXIF entries. They were visually inspected before this selection. The original files remain separate from the repository copies.

The source PDF's SHA-256 is `59758a7493a3b97cdae507233ece01f5f52e3a2a2b925d910655bc3d1dbda0bd`. Its original page is letter-sized. The public copy uses the PDF-coordinate rectangle `(66, 304, 529, 486)` as both media and crop boxes; this removes surrounding whitespace without redrawing the PCB. Its label orientation is the original export's orientation. This is documentation of component placement, rather than fabrication files or a full electrical schematic.

The electronics photo supports the presence of integrated boards, power hardware and wiring. The water-test photo supports the existence of a laboratory sensor setup. Neither establishes new measurements, end-to-end telemetry, autonomy, calibration accuracy or the source code flashed at the time.

The broader overview photograph, final-report extracts and exterior video are not included in this selection. No additional physical tests were performed while preparing these assets, and no new license is assigned here.
